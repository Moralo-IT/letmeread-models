# LetMeRead models

Public manifest of the on-device models the LetMeRead app downloads:
[`models.json`](models.json), served at
<https://moralo-it.github.io/letmeread-models/models.json>.

Each entry names a model file with its pinned download address, size in bytes,
SHA-256 and license. The app verifies size and checksum before it uses a file.

This repository contains nothing else. The file is published from the app
repository; do not edit it here.
